# D5 5-Minute Pitch Script (Draft)

## 0:00-0:30 Problem
Union Bank complaint handling is fragmented across channels, causing slow triage, duplicate effort, and poor customer transparency.

## 0:30-2:30 Solution + How It Works
Our Unified Customer Complaint Communication Dashboard collects complaints from multiple channels and applies AI for categorization, sentiment + urgency scoring, duplicate detection, SLA monitoring, and draft response generation. Managers get one operational view with trends by category/channel/region.

## 2:30-4:00 Demo Highlights
- Generated 300+ synthetic complaints from 5 channels.
- NLP model predicts categories.
- Urgent and negative complaints are prioritized.
- Duplicate complaints are identified.
- Draft responses are generated instantly.
- Dashboard shows SLA breaches and trend visuals.

## 4:00-4:30 Built vs Planned
Built now: end-to-end pipeline, dashboard, AI scoring, response drafts.
Planned next: multilingual model, real channel APIs, and policy-grounded Gen-AI with human review.
