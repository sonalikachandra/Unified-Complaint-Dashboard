# D2 Technical Demo Script (5-8 minutes)

1. Intro (30s)
- State PS5 objective and what the prototype demonstrates.

2. Show Input Data (45s)
- Open dashboard controls and generate synthetic multi-channel complaints.
- Mention channels and fields.

3. Run Pipeline (90s)
- Click Run Pipeline.
- Explain category prediction, sentiment scoring, urgency detection, and duplicate detection.

4. Unified Dashboard Walkthrough (120s)
- Show KPI cards.
- Filter by channel/category/urgency.
- Open records with high urgency and breached SLA.
- Show duplicate flagged complaints.

5. Gen-AI Drafting (60s)
- Show auto-generated response in table.
- Optionally switch to OpenAI mode if API key is available.

6. Trends and Management Insight (45s)
- Show channel/category/time charts.
- Explain how this supports branch-level action.

7. Real vs Simulated Disclosure (30s)
- Clarify synthetic data and real pipeline capabilities.

8. Close (20s)
- Summarize what is built now and next production steps.
